# Spinner

Glücksrad im Browser: Optionen eintragen, drehen, Gewinner wird zufällig gezogen.
Gebaut mit Deno und Hono, ein einziges `main.ts`, Canvas-Rad ohne Frontend-Abhängigkeiten.
Optionen und Spin-Dauer werden im `localStorage` gespeichert.

## Quick Start

1. [Deno](https://deno.com) installieren
2. `deno task start` ausführen
3. `http://localhost:8000` öffnen (anderer Port: `PORT=3000 deno task start`)
4. Entwicklung mit Auto-Reload: `deno task dev`
